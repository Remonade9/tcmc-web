# TCMC Website Design Brainstorm

## Context
- Target audience: Middle school students (ages 11–14) + parents + potential coaches
- Brand: Red and grey, wolf mascot, math/competition theme
- Tone: Professional yet approachable, academic but energetic

## Idea A: "Academic Crest" — Editorial Precision

**Design Movement:** Swiss International Typographic Style meets modern editorial

**Core Principles:**
1. Strong typographic hierarchy using weight contrast (heavy display vs. light body)
2. Structured asymmetric grid — content anchored left, accents right
3. Disciplined use of red as a single accent against a near-white and charcoal palette
4. Mathematical motifs (formulas, grids) used as decorative texture

**Color Philosophy:**
- Background: Off-white (#F7F5F2) — warm, paper-like, academic
- Primary red: #C8102E (Crimson) — confident, competitive
- Charcoal: #2B2B2B — serious, readable
- Mid-grey: #8A8A8A — supporting text and dividers
- Accent grey card: #EFEFEF

**Layout Paradigm:**
- Asymmetric two-column hero: large left text block, right-side image/logo
- Section dividers use thin red horizontal rules
- Cards in a staggered offset grid

**Signature Elements:**
1. Thin red vertical rule alongside section headings
2. Math formula fragments as decorative watermarks in section backgrounds
3. Bold serif display font (Playfair Display) for headings, clean sans (DM Sans) for body

**Interaction Philosophy:**
- Hover states: subtle red underline slide-in on links
- Cards lift with a soft shadow on hover
- Smooth scroll with section fade-in

**Animation:**
- Entrance: staggered fade-up for text blocks (0.2s delay per element)
- Hero: text slides in from left, image fades in from right
- No bouncy or playful animations — measured, deliberate

**Typography System:**
- Display: Playfair Display Bold (headings, hero)
- Body: DM Sans Regular/Medium
- Accent: DM Mono for math/numbers

## Idea B: "Challenger Bold" — Sports-Academy Hybrid ← SELECTED

**Design Movement:** Modern sports branding meets academic institution

**Core Principles:**
1. High-contrast bold typography that commands attention
2. Red as a dominant hero color, not just an accent
3. Diagonal cuts and strong geometric shapes for energy and forward motion
4. Clean information architecture that respects both students and parents

**Color Philosophy:**
- Hero red: #B91C1C (deep competition red) — power, urgency, achievement
- Dark charcoal: #1C1C1E — premium, serious
- Light grey: #F4F4F5 — breathing room, card backgrounds
- Mid grey: #71717A — secondary text
- Pure white: #FFFFFF — contrast, clarity

**Layout Paradigm:**
- Full-width hero with diagonal clip-path cut at bottom
- Horizontal scrolling timeline for competition calendar
- Alternating left/right content sections with bold numbering
- Sticky top navigation with red active indicator

**Signature Elements:**
1. Diagonal section transitions (clip-path) between red and white sections
2. Large bold numerals as decorative section anchors (01, 02, 03...)
3. Wolf silhouette used as a watermark/texture element

**Interaction Philosophy:**
- Red underline sweep on nav hover
- Card hover: border-left red stripe appears
- CTA buttons: solid red with white text, slight scale on hover

**Animation:**
- Hero: bold text "slams" in with a quick scale from 0.95→1 + fade
- Section entrance: slide-up with stagger
- Number counters animate when scrolled into view

**Typography System:**
- Display: Bebas Neue (hero numbers, large headings)
- Headings: Inter 700/800 (section titles)
- Body: Inter 400/500
- Accent: JetBrains Mono for math/code snippets

## Idea C: "Midnight Scholar" — Dark Academic

**Design Movement:** Dark academia aesthetic with competition-math energy

**Core Principles:**
1. Dark backgrounds create focus and reduce eye strain for late-night studying
2. Gold/amber accents replace red for warmth against dark backgrounds
3. Textured, layered depth — cards feel like pages in a notebook
4. Subtle noise/grain adds tactile quality

**Color Philosophy:**
- Background: Deep charcoal #141414
- Surface: #1E1E1E cards
- Gold accent: #D4A017
- Red: used sparingly for alerts/competition urgency
- Light text: #E8E8E8

**Layout Paradigm:**
- Magazine-style masonry grid for content sections
- Full-bleed dark hero with centered emblem
- Sidebar-style navigation on desktop

**Signature Elements:**
1. Parchment-texture overlays on card backgrounds
2. Thin gold borders on featured cards
3. Constellation/star pattern as background texture

**Typography System:**
- Display: EB Garamond Italic (headings)
- Body: Source Serif 4
- Mono: Fira Code

## Selected Design: **Idea B — "Challenger Bold"**

This approach best matches the dual goal: professional enough for parents and coaches, energetic enough to excite middle schoolers. The sports-academy aesthetic aligns with competition math's competitive spirit, and the red/grey palette directly matches the requested brand colors.
